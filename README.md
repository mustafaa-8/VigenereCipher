# 🔐 Vigenère Cipher System
A terminal-based text encryption and decryption program built using Python.

## 📌 Project Description
Vigenère Cipher System is a Python program that encrypts and decrypts text using the Vigenère Cipher technique.  
Each character is shifted by a randomly generated key, providing stronger encryption.  
Encrypted messages and corresponding shifts are saved in a JSON file for later decryption.

## 🚀 Features
- Encrypt text using Vigenère Cipher  
- Decrypt previously encrypted text  
- Random shift generation for each character  
- Persistent record storage in JSON file  
- Menu-driven terminal interface  

## 🛠️ Concepts Used
- Python functions  
- Random module  
- Loops and conditional statements  
- String manipulation  
- Pandas DataFrame  
- File handling (JSON)  

## 💾 Data Storage
Encrypted text and the list of shifts for each character are stored in a JSON file.  
This ensures accurate decryption and persistent record keeping across program executions.

## 📌 Learning Outcomes
- Understanding Vigenère Cipher encryption  
- Applying randomization for encryption keys  
- Managing data with pandas and JSON files  
- Enhancing string manipulation skills  
- Building menu-driven terminal applications
